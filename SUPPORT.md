# Getting help

- 📖 **Documentation:** start at [bspwmctl.github.io/docs](https://bspwmctl.github.io/docs/). Installation guides, modes, commands and keybindings are all there.
- 💬 **Questions:** ask in [Discussions](https://github.com/bspwmctl/bspwmctl/discussions).
- 🐛 **Bugs:** open a [bug report](https://github.com/bspwmctl/bspwmctl/issues/new?template=bug_report.yml). Include your distro, the bspwmctl version and the full output.
- 🔒 **Security issues:** follow the [security policy](SECURITY.md). Never report them publicly.
