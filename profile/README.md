### ⚡ Quick start

Download the package for your distro from the [latest release](https://github.com/bspwmctl/bspwmctl/releases), install it, and run:

```bash
bspwmctl install --standard
```

Log out, pick **bspwm** in your login screen, and you're done. See the [documentation](https://bspwmctl.github.io/docs/) for every option.

### ✨ Why bspwmctl

- **Official packages only.** Everything comes from `apt`, `pacman` or `dnf`. Nothing is compiled, everything can be updated and removed like any other package.
- **Works where you are.** Debian, Ubuntu, Arch, Fedora and their derivatives.
- **Ready to use.** Status bar, compositor, notifications, lock screen, screenshots, media keys and zsh, configured and working together.
- **Safe to try.** Your existing configs are backed up before anything is replaced, and `bspwmctl restore` brings them back.
