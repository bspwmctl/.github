<h3 align="center">
    Making bspwm setup simple, fast, and enjoyable.

<p align="center">
    bspwmctl is a tool that helps you install, configure, and manage <br />
    bspwm desktop environments without the headaches.
</p>

### ⚡ Quick Start

Download the package for your distro from the [latest release](https://github.com/bspwmctl/bspwmctl/releases), install it, then run:

</div>

<p align="center"><code>bspwmctl install --standard</code></p>

<p align="center">
    Debian · Ubuntu · Arch · Fedora · and their derivatives
</p>
